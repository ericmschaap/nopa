Nopa – playback proof

Three voice notes, spaced through a session, played from a locked phone. Milestone 1 prototype.

This page is not on HTTPS, so the microphone is unavailable. Upload still works.

1. Voice notes

Record (stops itself at 20 s) or upload. Notes are kept on this device between visits.

2. Settings


Gives you time to lock the phone, so all three notes come due while it is locked. Set 0 to play note 1 right away.

3. Run

Add three notes to enable Start.

4. Log

“Started” is when the note actually began. In mode B it is derived from the track position, so it stays accurate even if the page's JavaScript was asleep while locked; “JS saw it” shows how late the page noticed. The log proves the track reached the note – your ears confirm sound came out.
